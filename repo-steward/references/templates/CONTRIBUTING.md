# Contributing

Thanks for taking the time to contribute.

## Before you start

- Read [README](README.md) for usage.
- Read [docs/development.md](docs/development.md) for build and test commands.

## Ways to contribute

- **Bug**: open an issue with the **Bug** template. Include version, steps, expected vs actual, and logs.
- **Feature**: open an issue with the **Feature** template. Describe the problem first, then the proposal.
- **Pull request**: fork the repository, create a branch, run tests, open a PR.
